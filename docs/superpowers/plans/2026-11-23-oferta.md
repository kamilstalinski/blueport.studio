# Oferta zamiast kalkulatora — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Zastąpić kalkulator stroną `/oferta` (hub) i 4 podstronami usług (www, sklep, reklamy Meta/Google, wdrożenia AI), z jedną akcją „Umów rozmowę” → formularz kontaktowy z wybranym tematem.

**Architecture:** Dane usług w jednym pliku `src/constants/services.ts`; hub `src/app/oferta/page.tsx` i jeden szablon `src/app/oferta/[usluga]/page.tsx` (statyczne, `dynamicParams = false`) czytają z niego. Formularz kontaktowy dostaje prop `initialTopic`. Kalkulator, jego trasy, CSS, hook i `/api/leads` znikają na końcu, z 301 na `/oferta`.

**Tech Stack:** Next.js 16 (App Router), React 19, TypeScript, Vitest, Playwright, CSS w `src/styles/*.css` (klasy `bp-*`).

**Spec:** `docs/superpowers/specs/2026-11-23-oferta-design.md`

## Global Constraints

- Świat wizualny bez zmian: Tusz, linie siatki Grafit (`bp-rails`), radius 0, akcje jako `bp-row-act` (główna `bp-row-act--primary`, Sygnał), Geist Mono (`bp-mono`) tylko dla danych, Sygnał nigdy na Kobalcie.
- Przed każdą edycją UI przeczytaj `~/.claude/skills/impeccable/reference/craft-floor.md`; po skończonym UI uruchom raz `~/.claude/skills/impeccable/scripts/impeccable detect --json <zmienione pliki>` i napraw znaleziska.
- Reguły z taste-skill: jedna sekcja = 1–2 ekrany przy 1440×900; brak podpisów pod obrazami; ikony narzędzi tylko prawdziwe i faktycznie używane; najwyżej jeden nieruchomy diagram na stronę; hover: linkowana karta podnosi się o 2px, przyciski reagują; hero wchodzi raz przy ładowaniu; nic nie pojawia się „fade-in on scroll”. Nie kopiujemy kitu taste-skill (`system.css`, starter, gate).
- Żadnych zmyślonych liczb, klientów, efektów ani cytatów (PRODUCT.md).
- Polski, prosto, liczby zamiast przymiotników. Akcja główna wszędzie: tekst **„Umów rozmowę”**; akcja druga do huba: **„Zobacz ofertę”**.
- Ceny „od” wolno pisać tylko w `src/app/oferta/**`, `src/constants/services.ts`, `/cennik` i istniejących komponentach pakietów. Pliki z `SCOPED_FILES` w `src/constants/seoCopy.test.ts` zostają bez słów cenowych.
- Meta title/description `/oferta` i podstron bez słów `zł|cennik|koszt` (test w `e2e/subpages.spec.ts:482`).
- WCAG 2.2 AA, pełna obsługa klawiatury, brak przewijania w poziomie przy 320px.
- Kalkulator usuwamy dopiero w Task 6; wydanie dopiero po Task 8 (fakty AI/Ads).

## Review Focus

1. `/kontakt?temat=<śmieci>` albo brak parametru → formularz z tematem `strona`, bez błędu (Task 1).
2. Stare adresy `/kalkulator?pakiet=…`, `/wycena`, `/oferta/strony`, `/oferta/sklepy`, `/uslugi` → jeden 301 na żywą stronę, bez pętli z `/oferta` (Task 3, Task 6).
3. Nieznany slug `/oferta/cokolwiek` → 404, nie pusta strona (Task 3).
4. Usługa z `priceFrom: null` (AI/Ads przed faktami) → „Wycena po rozmowie”, nigdy „od null zł” / „od 0 zł” (Task 2, Task 3).
5. Reduced motion na hubie: ścieżka w hero od razu narysowana, nic ukrytego; 390px bez poziomego scrolla na hubie i podstronach (Task 4, Task 3).

```ts
export type ServiceSlug = "strony-www" | "sklepy-internetowe" | "reklamy-meta-google" | "wdrozenia-ai";
export type ServiceGroup = "klienci" | "automatyzacja";
export interface Service {
  slug: ServiceSlug;
  name: string;              // "Strona www", "Sklep internetowy", "Reklamy Meta i Google", "Wdrożenia AI"
  group: ServiceGroup;       // AI → "automatyzacja", reszta → "klienci"
  topic: ContactTopic;       // strona, sklep, reklamy, ai
  h1: string; metaTitle: string; metaDescription: string; lede: string;
  problem: string;           // 1 zdanie na kartę huba
  scope: readonly [string, string, string];
  priceFrom: number | null;  // null = brak faktu od właściciela
  priceUnit: "" | "/ mies." | "za proces";
  time: string | null;       // np. "od 7 dni roboczych"
  packages: readonly PackageId[];   // www: strona-start, strona-pro, projekt-dedykowany; sklep: sklep-online; inne: []
  forWho: readonly string[]; notFor: readonly string[];
  terms: readonly { term: string; text: string }[];
  proof: { kind: "work"; slugs: readonly WorkSlug[] } | { kind: "scenarios"; items: readonly { title: string; text: string }[]; tools: readonly string[] };
  faq: readonly { q: string; a: string }[];
}
export const SERVICES: readonly Service[];   // kolejność: www, sklep, reklamy, AI
export function getService(slug: string): Service | undefined;
export function priceLabel(service: Service): string; // "od 2 500 zł" / "od 900 zł / mies." / "Wycena po rozmowie"
```
